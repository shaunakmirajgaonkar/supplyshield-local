# SupplyShield Local — Project Overview

SupplyShield Local is a local-first supply-chain counterfeit-risk screening workspace.

## Core signals

- Pricing anomaly
- Shipment anomaly
- Seller behavior / reliability
- Product metadata quality
- Supplier anomaly

## Decision-support boundary

The resulting 0–100 score is a screening signal. It does not prove that a product or supplier is counterfeit. Human review and authorized supply-chain verification remain necessary.
